WARKOP WAWAT — Navy + Blue Modern
=================================

Isi proyek:
- index.html
- style.css
- player.js
- viewer.js

Deploy:
1. Ekstrak ZIP.
2. Upload/deploy folder yang berisi ke Netlify.
3. Pastikan keempat file berada pada folder root yang sama.

Catatan:
- Desain responsif untuk HP, tablet, TV browser, dan PC.
- Fitur lama dan URL stream yang sudah ada dipertahankan.
- URL stream contoh bisa kedaluwarsa atau tidak berfungsi bila aksesnya dibatasi. Gunakan stream yang Anda miliki atau berizin untuk digunakan.
- Situs web Netlify tidak otomatis menjadi aplikasi Android native dengan ExoPlayer. Pemutaran di browser bergantung pada dukungan browser, ketersediaan stream, dan CORS.
